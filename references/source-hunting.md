# 找资料：第 1 步的源清单与检索路径

> 目标：凑齐「3 份研报 + 客户年报/官网 + 监管目录」，不是读完，是**知道去哪找、每份取什么**。

## 1. 三份研报怎么选

| 选法 | 理由 |
|---|---|
| 2 份近 12 个月 + 1 份 3 年以上 | 近的看现状，老的看结构变化与被证伪的判断 |
| 优先券商行业深度（不是个股点评） | 深度报告会回答「行业怎么赚钱、谁在赚、变量是什么」 |
| 至少 1 份来自不同立场（如看多/看空） | 避免只读一种叙事 |

**公开可得的替代**：券商研报摘要/图表（东方财富、慧博、发现报告等公开页）、行业协会年度报告、招股书「行业概况」章节、咨询机构公开摘要、学术综述。付费全文拿不到时，用这些拼结构，并在 `sources.jsonl` 标 tier C。

## 2. 客户材料

| 材料 | 去哪找 | 取什么 |
|---|---|---|
| 年报 / 招股书 | 巨潮资讯、上交所/深交所、公司 IR 页 | 收入构成、客户/供应商、产能、战略措辞、风险提示 |
| 官网 / 公众号 / 新闻稿 | 公司官网、微信公众号、地方新闻 | 业务板块、项目案例、领导讲话（注意是宣传口径） |
| 招标 / 中标 / 环评 / 批文 | 政府采购网、公共资源交易中心、生态环境部门 | 项目规模、投资额、工期、承包关系 |
| 招聘 JD | 招聘网站 | 组织架构、岗位职责、技术栈、一线用词 |
| 制度 / 流程文件 | 客户提供（NDA 范围内） | 审批链、责任边界、口径定义 |

## 3. 监管目录（只建目录，不细读）

| 类别 | 典型来源 | 取什么 |
|---|---|---|
| 产业政策 / 规划 | 国家能源局、国家发改委 | 文件名称、年份、目标数字、有效状态 |
| 矿权 / 储量 | 自然资源部、省级自然资源厅 | 出让公告、储量规范、备案要求 |
| 安全 | 应急管理部、国家矿山安全监察局 | 抽采达标、瓦斯防治、安全设施 |
| 环保 | 生态环境部、省级生态环境厅 | 环评分类、水保、排放、甲烷控制 |
| 价格 / 补贴 / 管输 | 发改委、财政部、国家管网 | 定价机制、补贴办法、公平开放 |
| 标准 | 全国标准信息公共服务平台、行业标准 | 术语定义、储量估算、检测方法 |

**做法**：每个文件只记「名称 + 发布机关 + 文号/年份 + 管什么 + 链接」，正文留到需要时再读。监管目录本身就是 第 3 步 审批链的输入。

## 3.1 从业者内容源（公众号/知乎/B站/播客/论坛）

研报给你结构，从业者给你「现场怎么叫、实际怎么做」。找法：

| 源 | 怎么找 | 取什么 | 可信度处理 |
|---|---|---|---|
| 微信公众号 | 搜一搜/搜狗微信/行业社群转发；搜「行业词 + 科普/入门/避坑/一线」 | 术语、现场叫法、常见误解、流程细节 | 看作者/机构/日期；区分科普/软文/广告；标 tier C，好的标 B |
| 知乎 | 问题页、专栏、从业者长答 | 「外行不知道的 10 件事」、面试题、踩坑 | 匿名/无机构标 D；有实名+机构可标 B/C |
| B站/播客/小宇宙 | 访谈、复盘、培训课切片 | 口语化术语、行业故事、上下游关系 | 转述标 C；数字需回到官方源 |
| 行业论坛/贴吧/公开群文章 | 搜行业词 + 论坛 | 设备/工艺细节、招聘/培训帖 | 多为 D，仅作候选 |

**纪律**：从业者内容只用于「候选词 + 用法例句」，不作为关键数字的唯一来源；摘一句原话（≤60 字）+ 链接；记录作者/机构/日期；标注地域/企业差异。

## 4. 检索技巧

- 用「site:gov.cn 关键词」限定官方源；
- 用文件全称搜，比关键词更容易命中原文；
- 同一政策找「财政部/发改委/能源局」三个口径，注意废止与替代关系；
- 数字至少两个来源交叉；冲突时记录冲突，不静默取一个；
- 中文行业词常有别名（如「煤岩气」vs「深层煤层气」），用别名再搜一轮。

## 5. 检索顺序（不设固定时长）

| 顺序 | 动作 |
|---|---|
| 1 | 3 份研报，只抽结构、玩家、商业模式、关键变量 |
| 2 | 客户年报/招股书/官网，抽收入构成与战略措辞 |
| 3 | 监管目录，建表 |
| 4 | 合成 `chain.md`（含钱怎么流），标出缺口与冲突 |

资料少就快，拿不到就标「待验证」；不要为了凑数量硬找。

## 6. 产出检查

- `sources.jsonl` ≥ 8 条（与 `readiness.py` 证据闸门一致），A/B 级 ≥ 5 条；
- 价值链每个环节至少 1 个来源或明确「待验证」；
- 监管目录覆盖：产业政策、矿权/储量、安全、环保、价格/补贴、标准；
- 客户收入构成有 1 个以上来源（年报优先）。
