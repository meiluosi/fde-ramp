# 利益相关方画像与问题库

> 用途：第 4 步 找谁访谈、第 3 步 画决策链、见客户前写 brief、做对话演练。
> 每个角色给：他关心什么、他会怎么检验你、你可以问什么、你千万别说什么。

## 通用规律

- **一线**关心「能不能干、好不好干、出了事谁负责」；
- **技术**关心「参数、边界、先例、风险」；
- **商务**关心「价格、账期、竞争、客户关系」；
- **管理层**关心「战略、投资回报、合规、政绩/风险」；
- **监管/矿方**关心「合规、安全、责任边界」。

## 1. 一线操作/运维（如排采站长、集输站长）

| 项 | 内容 |
|---|---|
| 关心 | 日常怎么干、设备/人手够不够、指标压力、出了异常怎么办 |
| 检验你的方式 | 问一个现场细节，看你是否知道「文件写的」和「实际干的」不一样 |
| 可以问 | 「我猜这个环节是 X，实际是怎么干的？」「哪种情况文件里没写、但你们必须处理？」「最近一次异常是什么？」 |
| 别说 | 「你们是不是按标准流程执行？」（会得到「是」） |
| 红旗 | 对方只说「按制度」、不愿展开 → 换时间/换人，或先聊一个具体异常 |

## 2. 技术专家（地质/油藏/钻井/压裂工程师）

| 项 | 内容 |
|---|---|
| 关心 | 参数、适用边界、失败案例、数据质量、技术路线之争 |
| 检验你的方式 | 追问一个参数的适用条件；听你是否把相近概念混用 |
| 可以问 | 「这个参数在什么条件下会失效？」「两种技术路线你们怎么选？」「有没有反例？」 |
| 别说 | 「这个技术是不是更先进？」（会引发立场之争） |
| 红旗 | 你用了错误术语，对方开始用很浅的话应付你 |

## 3. 商务/销售/采购

| 项 | 内容 |
|---|---|
| 关心 | 价格、账期、客户关系、竞争对手、合同风险 |
| 检验你的方式 | 问你「你知道我们卖给谁、多少钱、账期多久吗」 |
| 可以问 | 「收入主要来自哪几类客户？」「价格是随行就市还是长协？」「最怕客户提什么条件？」 |
| 别说 | 「你们毛利大概多少？」（第一次见面太直接） |
| 红旗 | 对方开始只谈「我们很有优势」，不给具体数字 |

## 4. 管理层（总经理/副总/业务负责人）

| 项 | 内容 |
|---|---|
| 关心 | 战略、投资回报、合规、组织、上级/政府关系 |
| 检验你的方式 | 问你「你觉得我们这个行业未来三年最大的变量是什么」 |
| 可以问 | 「未来一年最优先的三件事？」「什么情况下会调整投资节奏？」「您最担心哪类风险？」 |
| 别说 | 「我研究了一下，我觉得你们应该……」 |
| 红旗 | 对方只讲愿景，不给取舍 → 说明你还没建立信任 |

## 5. 监管/政府/矿方（外部关键方）

| 项 | 内容 |
|---|---|
| 关心 | 合规、安全、责任、地方经济、矿权关系 |
| 检验你的方式 | 问你某个文件/审批的名称与口径 |
| 可以问 | 「这个环节主要看哪份文件？」「矿权重叠一般怎么协调？」「最近监管重点有什么变化？」 |
| 别说 | 「这个应该没人管吧？」 |
| 红旗 | 你用了错误的政策名称/文号 |

## 6. 客户的客户（下游：管道/电厂/工业用户）

| 项 | 内容 |
|---|---|
| 关心 | 气源稳定性、价格、质量（热值/杂质）、合同灵活性 |
| 检验你的方式 | 问你「你们的量能不能保证」 |
| 可以问 | 「采购决策最看重什么？」「什么情况下会换供应商？」「对气源/运输有什么硬要求？」 |
| 别说 | 「我们的气肯定比别家好」 |
| 红旗 | 对方只谈价格，不谈质量/稳定性 |

## 对话演练的三种人设（用于 `ramp_drill` / 自测）

| 人设 | 开场 | 压力点 | 通过标准 |
|---|---|---|---|
| 怀疑的站长 | 「你说你是来帮我们解决问题的？我们这情况你了解多少？」 | 追问现场细节、异常处理 | 能接住 2 个细节追问，并承认不知道的部分 |
| 严谨的技术专家 | 「你先说说，这个参数在什么条件下不适用？」 | 概念辨析、边界条件 | 不混用近邻概念，能说清适用边界 |
| 忙碌的管理层 | 「给你十分钟，说说你能带来什么？」 | 时间压力、要结论 | 3 句话说清价值，并问出一个对方愿意答的问题 |

## 问题库（按场景）

### 破冰（不要问行业概况）

- 「我看了你们去年的 XX 项目，里面提到 X，这个在你们内部是怎么叫的？」
- 「我画了张图，您帮我看看哪里最不对？」

### 挖隐性知识

- 「哪种情况是文件里没写、但你们必须处理的？」
- 「最近一次让你们头疼的异常是什么？」
- 「如果我是个新人，最容易在哪一步踩坑？」

### 挖决策链

- 「这件事最后是谁签字？」
- 「预算一般什么时候定？」
- 「如果我们要推进，通常要过哪几关？」

### 挖竞争/风险

- 「你们最怕客户提什么条件？」
- 「如果 X 发生，你们会怎么应对？」
- 「这个行业过去三年最大的变化是什么？」

### 收尾

- 「还有谁会不同意这张图？我应该再找谁聊？」
- 「下次我带什么来，您会觉得有用？」

## 访谈后的自检

1. 我是否至少被纠正了 3 处？
2. 我是否拿到了 1 条公开资料里没有的信息？
3. 对方是否主动给了我文件/人名/下一步？
4. 我是否用错了术语而没被纠正？（很可能对方已经把你当外行，不再深说）
