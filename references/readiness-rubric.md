# 怎么判断自己准备好了

> 五个维度，每项 0–4 分。**目标**：见客户前五项都到 3 分。**最低门槛**：五项都不低于 2 分、平均到 3 分、结构和语言至少 3 分，并且真的去一线改过图（至少 5 处修正）。
>
> 这不是考试，是一张「还差什么」的清单。每一分都要能指到具体文件，不能凭感觉。

## 两种模式

| 模式 | 用途 | 证据要求 |
|---|---|---|
| `explore` | 内部探索、见客户前练习 | 公开源可以；模拟访谈只能演示，不能对外 |
| `client-ready` | 拿给客户/立项会 | 真实访谈修正；≥3 个 `verified` 术语；A/B 来源 ≥5 且占比 ≥50%；`decision-brief.md` 已填；`provenance.evidence=customer` 且 `reviewedBy` 非空 |

`readiness --client --check` 会检查这些；示例永远是 explore。

## 打分总则

- **看证据**：说「语言 3 分」，要能指到 `glossary.md` 的哪几行、`calibration-log.md` 的哪条记录。
- **就低不就高**：一个维度里有一项关键能力不达标，按低档记。
- **只看行为**：能用一句人话解释、能画出图、能接住追问，才算；「我感觉懂了」不算。
- **分数可以降**：访谈发现原来标「有依据」的东西错了，相关维度要降分并记录原因。

## 1. 结构：行业怎么赚钱

| 分 | 你要能做到 |
|---|---|
| 0 | 说不出这个行业分几段、靠什么赚钱 |
| 1 | 能背出上中下游，但说不清各段之间交易什么 |
| 2 | 能画出价值链草图，一半以上节点有来源；能说出主要收入项 |
| 3 | 能解释利润池分布、成本大头、关键瓶颈；能说出「什么会改变这个结构」 |
| 4 | 能对比两种商业模式/技术路线，说明各自在什么条件下更优；能指出行业当前的共识与分歧 |

**证据**：`value-chain.md` 的节点与来源覆盖率；你能不能在白板 5 分钟内复述。

## 2. 语言：行话用不用得准

| 分 | 你要能做到 |
|---|---|
| 0 | 认识不到 10 个行业词 |
| 1 | 认识一些词，但会把近邻概念混用 |
| 2 | 约 50 词，能说一句人话；个别用错或过时 |
| 3 | 50 词用得准；能主动辨析 10 组近邻概念；知道哪些说法是客户/地域特有的 |
| 4 | 能在对话中自然使用行话，听懂对方的省略与暗示；能识别对方在用什么口径说话 |

**证据**：`glossary.md` 的状态分布、随机抽 10 词的现场解释、`corrections.md` 里术语被纠正的记录。

## 3. 玩家：链上都有谁

| 分 | 你要能做到 |
|---|---|
| 0 | 叫不出三家行业公司 |
| 1 | 能说出几家大公司，但说不清各自做什么 |
| 2 | 能列出 ≥10 家玩家及其角色（含客户、竞对、供应商、监管相关） |
| 3 | 能说清主要玩家的定位、近一年公开动作、彼此关系 |
| 4 | 能推演「如果 X 发生，谁受益、谁受损」，并能说出判断依据 |

**证据**：`chain.md` 的玩家表与关系表；`sources.jsonl` 里近一年来源的数量。

## 4. 决策：客户内部怎么转

| 分 | 你要能做到 |
|---|---|
| 0 | 不知道谁拍板、谁使用、谁买单 |
| 1 | 知道有「技术/商务/管理层」，但说不清关系 |
| 2 | 能划分业务域、画出审批链，标出关键角色 |
| 3 | 知道每个角色的 KPI、预算周期、采购路径，以及他们各自最怕什么；活动表能被一线逐行纠正 |
| 4 | 能预测某个提议会在哪一步被谁卡住，并知道怎么绕/怎么解 |

**证据**：`domains.md`、`flow.md` 的审批链、`activities.md`（做什么/谁做/影响谁/工具/背景）、`brief.md` 的角色诉求表。

## 5. 对话：现场撑不撑得住

| 分 | 你要能做到 |
|---|---|
| 0 | 撑不过 10 分钟，只能问泛问题 |
| 1 | 能问出一些具体问题，但接不住追问 |
| 2 | 能回答已知问题；能按清单问完 10 个问题 |
| 3 | 能问出 5 个让对方愿意展开的好问题；能接住 3 个反对意见；不知道时能承认并追问 |
| 4 | 能引导对话节奏，能在对方含糊时识别口径，能在结束时让对方主动给下一步 |

**证据**：`open-questions.md` 的自测、`drill-scorecard.md` 的演练记录、第 4 步访谈中对方的反应（是否主动展开/给材料/介绍人）。

## 总分与门槛

- 总分 = 五个维度的平均分（0–4）。
- **最低门槛**：五项都不低于 2 分、平均到 3 分、结构和语言至少 3 分。
- **证据门槛**（自检脚本会查，光自报分数不算）：
  - 至少 5 处已填的访谈修正；
  - 至少 8 条来源；
  - 至少 20 个术语行；
  - 至少 5 条待验证；
  - 至少 10 个玩家、5 条关系；
  - 至少 3 个业务域、10 行活动（目标 15 行）。
- 不达标时，输出「差在哪、下一次做什么」，而不是「差不多可以了」。

## 三个容易骗自己的地方

1. **用文档字数代替能力**：读完 20 篇研报不等于结构 3 分；能在白板讲清才算。
2. **用自己的感觉代替对方反应**：对话分要看对方是否展开、是否给材料、是否介绍人，不是「我觉得聊得挺好」。
3. **一次评分定终身**：每次访谈/演练后重评；分数下降是发现问题的证据，不是失败。

