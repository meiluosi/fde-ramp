## 1. 我画的八个业务域（先被否这一层）

```mermaid
flowchart LR
  D1["D1 资源与矿权"] --> D2["D2 勘探与开发方案"]
  D2 --> D3["D3 钻完井与压裂"]
  D3 --> D4["D4 生产与排采"]
  D4 --> D5["D5 集输与销售"]
  D5 --> D7["D7 财务/投资/补贴"]
  D6["D6 安全与环保"] -.否决权.-> D1
  D6 -.否决权.-> D4
  D8["D8 数字化/IT ❓"] -.数据.-> D4
  D8 -.报表.-> D7
```

**我预判会被改的 3 处**：
1. D1/D2 可能是一个部门（"勘探开发部"）。
2. D5 的"销售"可能在集团层面，不在区块公司。
3. D8 可能根本不存在独立部门。

**开场话术**：
> "我按公开信息把贵司拆成八块能力，画得比较粗。**您先帮我看这个分法对不对——哪两块其实是一个部门？哪一块我漏了？**"

## 3. 现场怎么用

1. **先给域图，不给活动表**（域图一眼能看懂，活动表会让人进入"审阅模式"）。
2. 让对方改域图：划掉、合并、补一个框。
3. 再给活动表，只问三列：**"谁做"、"用什么"、"这一步是不是这样"**。
4. 记录"被改的格子"，不要辩解。

**话术**：
> "这张表里我最不确定的是'谁做'和'用什么系统'——**您直接在上面改，我回去重画。**"
