# examples：这套案例包跑出来的示例产物

> 这是一组"半成品"示例，不是标准答案。每一份都刻意保留 ❓——因为这个方法的交付物不是一份行业报告，而是**一张等着被否定的地图**。
> 场景假设：客户是山西一家省属煤层气公司，FDE 一个人上场。换个客户、换个产区，结论会全变。

## 这组示例各自回答什么问题

| 文件 | 它回答的问题 | 长什么样 |
|---|---|---|
| `step1-value-chain.md` | 这门生意靠什么赚钱、钱卡在哪 | 一张价值链草图 + 3 条钱流 + 5 个填不出来的数字 |
| `step2-glossary-10.md` | 跟客户说话要用哪些词、哪些我拿不准 | 10 张术语卡（带 `public` / `needs-customer` 状态） |
| `step3-flow-guesses.md` | 客户的活是按什么顺序干的 | 一张满 ❓ 的流程图 + 待验证候选 |
| `step3-domains-activities.md` | 客户由哪几块业务组成、每个环节谁在做 | 8 个业务域 + 8 行活动表 |
| `step3-verification-top5.md` | 怎么开口，让一线愿意帮我改 | 5 条"我画了…您帮我改"的问法 |

## 一眼能看到的三个特征

1. **❓ 比 ✅ 多**：不是没做功课，是刻意标出不确定。
2. **每个数字都带出处**：`[S15]` 指向 `../sources.jsonl`，客户可以查。
3. **动词是"您帮我改"**，不是"请您介绍"。

## 不要这样用

- ❌ 把这组示例当模板套到别的行业：结构可复用，**内容不可复用**。
- ❌ 把这里的 ❓ 删掉再给客户：等于把最诚实的信息丢了。
- ❌ 用这里的数字对外汇报：它们是公开源的二手转述。

## 还差一块

"被一线改完之后的记录"不在这组示例里——那属于现场产物，得你自己去拿。记录模板在 `../../templates/corrections.md`。
