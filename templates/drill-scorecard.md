# 对话演练评分卡

> 用途：见客户前自测，或让一个 subagent 扮演对方、另一个打分。
> 一次演练 = 1 个人设 × 10–15 分钟 × 8–12 个问题。

## 人设

- 角色：一线 / 技术 / 商务 / 管理层 / 监管 / 下游
- 态度：配合 / 怀疑 / 忙碌 / 挑刺
- 背景：他今天为什么愿意见你

## 评分维度（每项 0–4）

| 维度 | 0 | 2 | 4 |
|---|---|---|---|
| 事实准确 | 说错关键事实 | 大部分对，个别口径错 | 准确，且知道哪些是推断 |
| 具体性 | 全是泛泛而谈 | 有具体环节/数字 | 能举出具体案例/反例/边界 |
| 取舍意识 | 只讲优点 | 能说 trade-off | 能说清「什么条件下选 A 不选 B」 |
| 问题质量 | 问「请讲讲」 | 问具体流程问题 | 问出对方愿意展开、且能暴露隐性知识的问题 |
| 行话使用 | 用错/不用 | 基本正确 | 自然，能识别对方口径变化 |
| 不知道时 | 硬编 | 承认不知道 | 承认并追问，把不知道变成下一步 |

## 单轮记录

```markdown
### Q3 · 「你们排采是自营还是外包？」
- 我的回答：
- 对方追问：
- 我接住了吗：
- 事实/口径问题：
- 更好的问法/答法：
- 分数：事实 3 / 具体 2 / 取舍 2 / 问题 3 / 行话 3 / 不知道 3
```

| 人设 | 事实 | 具体 | 取舍 | 问题 | 行话 | 不知道 | 平均 |
|---|---|---|---|---|---|---|---|

| 忙碌的管理层 |  |  |  |  |  |  |  |

**通过线**：平均 ≥3，且「问题质量」≥3，且没有一项 ≤1。

## 反模式

- 演练变成你单方面输出 → 对方没追问，说明你的话没引起兴趣
- 对方一直配合 → 人设太温和，换「怀疑/忙碌」重来
- 你把不知道硬编过去 → 直接判 0 分，这是最危险的现场行为
