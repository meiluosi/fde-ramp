**判断规则**：

- 错误代价高 → 必须有人复核，不能全自动；

## 5.5 试点计划（pilot）

| 项目 | 内容 |
|---|---|
| 试点范围 | 一个班组 / 一个品类 / 一条产线 |
| 基线 | 现在的耗时、频次、出错率、成本 |
| 目标 | 试点后要改善的 1–2 个指标（不要贪多） |
| 测量方式 | 系统日志 / 抽样 / 人工记录；谁记录 |
| 护栏指标 | 质量、合规、投诉、返工不能恶化 |
| 停止条件 | 什么情况下停掉/回滚 |
| 负责人 | 业务 owner + 技术 owner |
| 采用指标 | 使用率、周活跃、人工接管率 |

## 6. 净 ROI（不是毛上限）

```text
毛改进上限 = 每天人力成本 + 每天风险成本
可实现收益 = 毛改进上限 × 可实现比例 × 250 天
净收益     = 可实现收益 - 建设成本 - 年运行成本
回收期     = 建设成本 ÷ (可实现收益 - 年运行成本)
```
