# 煤层气 · 对话演练评分卡（示例）

> 示例：模拟一次「怀疑的排采站长」对话，用来演示评分卡怎么记。真实项目请用真人/真实场景。

## 人设

- 角色：排采站长（一线）
- 态度：怀疑
- 背景：你带着活动表来请对方改

## 单轮记录

### Q1 · 「你们这个排采制度写的是定产气？」

- 我的回答：不是，一般前期定产水、中后期控井底流压，不采用定产气（[S26]）。
- 对方追问：那套压怎么控？什么时候调？
- 我接住了吗：部分接住——知道原则，但不知道具体套压区间和调整规则。
- 更好的问法：先承认不知道，再问「咱们站一般套压控制在什么范围？什么情况下会调？」
- 分数：事实 3 / 具体 2 / 取舍 2 / 问题 3 / 行话 3 / 不知道 3

### Q2 · 「你表里写排采是自有队伍，不对」

- 我的回答：承认，问「哪些井外包、怎么结算？」
- 对方补充：偏远井/低产井外包，按产量结算。
- 记录：写进 `corrections.md`（示例中为修正 5 的同类）。
- 分数：事实 2 / 具体 2 / 取舍 2 / 问题 3 / 行话 3 / 不知道 3

## 汇总

| 人设 | 事实 | 具体 | 取舍 | 问题 | 行话 | 不知道 | 平均 |
|---|---|---|---|---|---|---|---|
| 怀疑的排采站长 | 3 | 2 | 2 | 3 | 3 | 3 | 2.67 |

**结论**：能开口、能接住追问，但具体参数不足；下次见面前补「排采制度/套压/修井」3 个点。
