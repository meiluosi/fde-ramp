## 每一步的检查

- [x] 第 1 步后：能讲清「行业靠什么赚钱、卡在哪」，并说清 ≥10 个玩家的位置与关系（14 家/类、10 条关系）
- [x] 第 2 步后：随机抽 10 个词能用人话解释并辨析近邻（77 候选、12 组易混对）
- [x] 第 3 步后：≥3 个业务域、活动表 ≥15 行、图上有 ≥5 个具体 ❓（8 域、25 行、12 个 ❓ 节点）
- [x] 第 4 步后：拿到 ≥5 处修正，每处都知道「为什么」（示例为模拟访谈，5 处）
- [x] 收尾：五个维度都 ≥3（示例自评，仅演示）

## 风险与依赖

- 没有客户内部资料：所有客户相关判断标「待客户确认」；术语最高「公开说法」（本示例 0 个已校准）
- 公开源不足：标「未找到公开源」，不编
- 模拟访谈只用于展示记录格式，真实项目必须由人现场完成
- 行业数据有两个口径（网文报告 574.72 亿元 / 数字阅读报告 789.37 亿元），对外汇报前必须确认
