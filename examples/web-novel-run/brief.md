# 网络文学 · 会前 brief（示例运行）

- 见谁：某中型网文平台内容/运营负责人（示例，非真实客户）
- 时间/地点：示例 D+1（虚构）
- 目标：确认四块收入口径、推荐位分配权、签约类型比例、审核外包、IP 台账现状；拿到 3 份内部材料
- 对方可能的目标：判断你懂不懂"免费与付费两套 KPI"，能不能解决内容成本与 IP 变现的错配

## 他关心什么（3 条，按重要性）

1. 广告收入占比上升后，**免费书与付费书的 KPI 打架**，运营和商业化互相不认账。
2. 作者成本（保底 + 全勤 + 分成）是最大成本项，**保底坏账**没人算得清。
3. IP 授权（尤其短剧）增长快，但**授权台账是 Excel**，到期与重复授权风险高。

## 我确定的（有来源）

- 2025 年行业营收 574.72 亿元，广告 274.49 亿 > 订阅 159.95 亿 > 版权 117.01 亿 [S01]。
- 2025 年 IP 改编 91392 部、+9.78%，增量主要来自短剧和 AI 漫剧 [S01]。
- 平台做网络出版服务须持证，要有内容审校制度与 8 名以上专职编辑出版人员 [S13]。
- 微短剧 2024-06 起分类分层审核（100 万以上/30—100 万/30 万以下三档）[S12]。
- AI 生成合成内容有标识义务（2025 年 3 月四部门办法）[S19]；16 家平台已签反洗稿公约 [S10]。

## 5 个必问（按顺序）

1. 「我按公开资料画了价值链和活动表，您帮我看看哪几行不对？」
2. 「咱们收入四块（订阅/广告/版权/其他）实际占比多少？广告里含不含'其他'？」
3. 「签约三类合同（买断/保底+分成/纯分成）各占多少？保底怎么抵扣？」
4. 「推荐位是算法还是人工？人工位谁批、有没有配额？」
5. 「IP 授权台账在哪个系统？短剧备案谁去备？」

## 3 个雷区（不要说/不要问）

1. 不要问"你们毛利率多少"——第一次见面太直接。
2. 不要把"短剧"和"影视化"混着说——备案体系与金额量级都不同。
3. 不要编具体厂商/系统名——工具只写类别。
