# 网络文学 · 对话演练评分卡（示例运行）

> 示例：模拟一次「怀疑的运营总监」对话，用来演示评分卡怎么记。真实项目请用真人/真实场景。
> 人设与对话均为虚构，只演示记录格式。

## 人设

- 角色：运营总监（管理层偏业务）
- 态度：怀疑 + 忙碌
- 背景：你带着 16 列活动表和价值链图来请对方改，对方只有 15 分钟

## 单轮记录

### Q1 · 「你说我们收入靠广告，凭什么？」

- 我的回答：不是"靠"广告，是行业 2025 年广告 274.49 亿 > 订阅 159.95 亿 [S01]；具体到贵司要看四块占比。
- 对方追问：那订阅还有没有价值？
- 我接住了吗：接住了——订阅是利润与调性，广告是流量与规模，两者 KPI 不同。
- 更好的问法：先请对方填四块占比，再说结论。
- 分数：事实 3 / 具体 3 / 取舍 3 / 问题 3 / 行话 3 / 不知道 3

### Q2 · 「推荐位不是算法自动分的吗？」

- 我的回答：我原来也这么以为；但模拟访谈提到人工推荐位仍有配额与审批。
- 对方补充：人工位主要给新书冷启动和重点书，算法管长尾。
- 记录：写进 `corrections.md` 修正 2。
- 分数：事实 2 / 具体 2 / 取舍 3 / 问题 3 / 行话 3 / 不知道 3

### Q3 · 「短剧授权你们懂吗？」

- 我的回答：懂流程不懂贵司条款——授权→制作→备案→上线→分账，备案按投资额分层 [S12]。
- 对方追问：备案谁去？
- 我接住了吗：部分接住——知道规则，不知道客户是平台备还是制作方备。
- 更好的问法：直接问"上一部短剧是谁去备案的、花了多久？"
- 分数：事实 3 / 具体 2 / 取舍 2 / 问题 3 / 行话 3 / 不知道 3

## 汇总

| 人设 | 事实 | 具体 | 取舍 | 问题 | 行话 | 不知道 | 平均 |
|---|---|---|---|---|---|---|---|
| 怀疑的运营总监 | 3 | 2 | 3 | 3 | 3 | 3 | 2.83 |
| 忙碌的版权商务 | 3 | 2 | 2 | 3 | 3 | 3 | 2.67 |

**结论**：能开口、能接住追问；具体条款与客户内部数字不足，下一次见面前补「收入四块、推荐位审批、短剧备案主体」3 个点。
