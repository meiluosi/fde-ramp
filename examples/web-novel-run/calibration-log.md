## 规则

- 一条校准必须能指到**具体文档 + 位置**或**具体人 + 场合**；
- 客户说「看情况/分平台」→ 保持「待客户确认」，把分歧记在备注；
- 客户没听过这个词 → 从 50 词定稿里删掉，不要硬留；
- 每次校准后同步更新 `glossary.md` 与 `state.json` 的计数。

## 本示例重点待校准的 10 个词（见客户时优先问）

1. 订阅 / 会员 / 广告 —— 客户四块收入怎么分。
2. 首订 / 均订 —— 统计窗口。
3. 追读 / 完读率 —— 分母是点击还是曝光。
4. 保底 / 买断 / 纯分成 —— 合同类型比例。
5. 全勤 —— 日更门槛与请假规则。
6. 推荐位 / 榜单 —— 人工与算法的边界。
7. 全版权 / 优先权 / 竞业 —— 合同实际写法。
8. 短剧 / 微短剧 —— 客户内部怎么叫。
9. 出海 / 翻译 —— 自建还是授权。
10. AI 生成 / AI 辅助 —— 客户内部怎么划界。
